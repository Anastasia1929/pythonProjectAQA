# Автотесты для проекта (Week 1)

Проект содержит базовую структуру для автоматизации тестирования на Python с использованием фреймворка `pytest`.

##  Инструкция по подготовке и запуску

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3.10+ и развернуто виртуальное окружение.
Если окружение не создано, выполните в терминале:
python3 -m venv .venv
source .venv/bin/activate

### 2. Установка зависимостей
Для установки всех необходимых библиотек (включая `pytest`), запустите команду:
pip install -r requirements.txt

### 3. Запуск тестов
Чтобы запустить все автотесты в проекте локально, выполните команду:
pytest

*Благодаря настройкам в файле `pytest.ini`, тесты автоматически запустятся в подробном режиме (verbose) из папки `tests`.*
